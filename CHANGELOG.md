# Changelog

## 1.0.1

- Default drop is now a First Aid Kit or Bandages (was the Roots luggage pool)

## 1.0.0

- Initial release: dead and knocked-out zombies have a chance to drop an item
- Host-only. Default 25% chance, one item from the Roots luggage pool
- Configure chance, item list, loot pool, and drop-on-knockout in `PeakZombieLoot.cfg`
